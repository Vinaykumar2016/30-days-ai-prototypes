## 🛠️ How to Use This Repo
1. Clone this repository:
   ```bash
   git clone https://github.com/poweredbyvinay/30-days-ai-prototypes.git
   ```
2. Navigate to any day's directory:
   ```bash
   cd Day01_ATS_Resume_Optimizer
   ```
3. Open `index.html` directly in any web browser, or host it on your own server.
