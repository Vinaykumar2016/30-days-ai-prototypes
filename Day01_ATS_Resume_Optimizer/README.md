## 🎯 What it Does
Most job applications submitted on **Naukri**, **LinkedIn**, and corporate job portals get filtered out automatically by **Applicant Tracking Systems (ATS)** before any human recruiter reads them.

This lightweight, 100% client-side web application solves that pain:
1. **Scans Target Job Description (JD)** and extracts critical hard tech keywords.
2. **Compares Against Your Resume** to calculate a live **ATS Compatibility Match Score** (0–100%).
3. **Pinpoints Missing High-Impact Keywords** you need to add.
4. **Generates STAR-Format Action Bullets** weaving in missing skills with measurable metrics.
5. **100% Private:** Operates entirely within your browser — zero cloud uploads or data tracking.

## 🛠️ How to Deploy on Your Own Domain (Hostinger / cPanel / Netlify)

### Option A: Hostinger / cPanel Subdirectory
1. Open Hostinger **File Manager** (or cPanel).
2. Go to `public_html/` and create a new directory named `resume`.
3. Upload `index.html` into `public_html/resume/`.
4. Done! It is now live at `https://yourdomain.com/resume`.

### Option B: Netlify / Vercel
1. Drag and drop the `Day01_ATS_Resume_Optimizer` folder directly into [Netlify Drop](https://app.netlify.com/drop).
2. Instantly live with a free SSL link in 5 seconds.
